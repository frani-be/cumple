# cumple.frani.be

Invitación al cumpleaños de Frani: **tallarinata + bingo** a beneficio de Alonso, que perdió la inversión de su tienda en Pichilemu tras un robo.

En vez de regalos: donaciones por Mercado Pago.

## Desarrollo

```sh
npm install
npm run dev
```

Build de producción:

```sh
npm run build
npm run preview
```

Sitio estático (Astro + Tailwind 4). El `public/CNAME` apunta a `cumple.frani.be` para GitHub Pages.
